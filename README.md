## 协作查阅与引用方式

1. 先确认正在查阅的是 S01 对应文件，再按上表 PDF 页序定位，并对照印刷页码。
2. 提交意见时注明问题编号、文件版本、PDF 页序、印刷页码及原文；涉及图纸时附截图或圈出位置。
3. 将“原文事实”“居民陈述”“分析意见”“待核事项”分开记录；补充答复时保留来源、日期和处理结果。
4. 新版方案或正式合同入库时保留旧版，逐项比较工程范围、金额、点位及授权变化。

引用示例：**[S01，PDF 第 19 页／印刷第 57 页，R01]**：“楼道钢窗此次不更换。全部除锈刷漆”。请设计单位解释与 PDF 第 5 页“楼梯间窗户换新”的关系。
